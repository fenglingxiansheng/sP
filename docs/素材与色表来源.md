# 素材与色表来源

## Artkal S 色表

- 官方入口：https://www.artkalfusebeads.com/pages/s-color-chart
- 官方 RGB 文件：https://cdn.shopify.com/s/files/1/1323/8195/files/S_MIDI_Beads_RGB_Color_Chart_2024.pdf?v=1744686607
- 文件名：`S_MIDI_Beads_RGB_Color_Chart_2024.pdf`。
- 核验日期：2026-10-12。
- 源 PDF SHA-256：`cddac1e1b02bc731639665386388e98f5019584fc36cbd63631bc19bcea74c03`。
- 应用数据：`src/data/artkal-s.json`，版本 `2024-rgb-156`。

通过 PDF 文本层提取前两页中 `S` 后跟数字的色号及对应 RGB，按色号数字顺序排列。校验为 S01～S159 共 159 个编号，排除 S41（金）、S42（银）、S63（铜）三个没有数字 RGB 的条目，得到 156 色。未加入 SE 编号、荧光、透明等额外系列，不以页面宣称的全部颜色数量充当实际支持数量。

颜色数值直接来自官方 RGB 表，没有从商品照片取色，也没有虚构数值。色表存在相同 RGB，例如 S18 与 S94；保留两种真实色号，自动匹配同距时选择色表中先出现的编号，用户仍可手动选用另一编号。

RGB 按 sRGB 解释，转换为 D65 CIELAB，使用 CIE76 距离。这是本 Demo 的计算约定，不代表厂家公布了色差算法或实物测色值。官方文件也提示屏幕与实物的差异。

这里只使用色号与 RGB 数值并保留出处，不将整份官方 PDF 或品牌图片纳入仓库。未发现明确授权将官方美术素材再分发的声明，项目不宣称获得品牌授权或官方背书。

## 样例与界面素材

- `public/samples/flower.png`：本次开发通过几何像素绘制生成的原创 32×32 小花，无第三方角色素材。
- `flower.jpg`：同一原创图案的 JPEG 版本，用于格式检查；透明背景转为黑底。
- `half-transparent.png`、`transparent.png`：程序生成的透明处理测试样例。
- 界面图标：项目内简单 SVG 路径；未使用第三方图片、远程字体或付费素材。
- 字体：系统字体，PNG 在当前浏览器中绘制，因此不同系统字体可能略有差别。

样例创建和 PDF 整理曾使用本机已有 Python 工具，应用运行与 npm 测试不依赖 Python。
